# قعدة تصوير 📸

لعبة من «قعدة رواق» — مشروع **صار بدها قعدة** · إعداد م. إياد حلوبي (@eyad.hloubi)

10 تحديات كاميرا للقعدة، كل لاعب من موبايله، والكاميرا هي الحَكَم:
لا ترمش · صيّاد الألوان · التصوير الأعمى · ثبّت الإطار · غمزات · لا تضحك · قلّد الإيموجي · تمثال · حواجب طايرة · راسك هو الجويستيك.

- عجلة الحظ بتختار اللعبة، وما في لعبة بتتكرر بنفس الدورة، وكل جولة إلها تحدّي مختلف (seed جديد).
- الكل بيبلّش سوا بنفس اللحظة (ساعة السيرفر).
- 3 أوضاع: فردي / الفريق كله / كل عضو جولة، مع قائد لكل فريق ورهان ×2 بموافقة الفرق التانية.
- الريس: مرّر اللعبة، عيد اللعبة (والنتيجة بتنلغى)، سكّر الجولة، طلّع لاعب، عدّل الأسماء، سلّم الريس.
- كشف الوجه كله على موبايل اللاعب (MediaPipe Face Landmarker)، وما في ولا لقطة بتطلع لبرا الموبايل.
- بالآخر: حفلة كشف أو كشف دفعة وحدة، وصورة ستوري بخيارين (ستوري الترتيب / ألبوم قعدتي) × 3 أشكال × فاتح وداكن.
- وضع «جرّب لحالك» بلاعبين وهميين: افتح الرابط مع `?demo=1`.
- إحصائيات بلا أسماء: `/stats?key=المفتاح`.

## الرفع على GitHub

1. افتح [github.com/new](https://github.com/new) واعمل مستودع جديد باسم `qa3da-taswir` (خلّيه Private إذا بدك).
2. بصفحة المستودع اكبس **uploading an existing file**.
3. فك ضغط الملف عندك، واسحب **كل الملفات والمجلدات اللي جوّاه** (مو المجلد نفسه) لصفحة الرفع.
4. اكبس **Commit changes**.

> ملاحظة: مجلد `node_modules` مو موجود بالحزمة، و Render بينزّله لحاله.

## النشر على Render

1. ادخل على [dashboard.render.com](https://dashboard.render.com) ← **New** ← **Blueprint**.
2. اختار المستودع `qa3da-taswir`. Render رح يقرأ ملف `render.yaml` لحاله.
3. اكبس **Apply** واستنى لحد ما يصير **Live** (دقيقتين تقريباً).
4. الرابط بيطلع متل: `https://qa3da-taswir.onrender.com` — هاد اللي بتحطه بالـBio.

### مفتاح الإحصائيات
بصفحة الخدمة على Render ← **Environment** ← بتلاقي `STATS_KEY` (انولّد لحاله). افتح:
`https://رابطك/stats?key=STATS_KEY`

### حفظ الإحصائيات بشكل دائم (اختياري)
النسخة المجانية من Render بتمسح الملفات لما الخدمة ترجع تشتغل. إذا بدك الإحصائيات تضل:
اعمل قاعدة **PostgreSQL** مجانية على Render، وانسخ الـ**Internal Database URL**، وحطه بمتغير اسمه `DATABASE_URL` بخدمة اللعبة.

## ملاحظات مهمة

- **الكاميرا بدها HTTPS**: Render بيعطيك HTTPS لحاله. محلياً بتشتغل على `localhost` بس.
- **أول فتحة بعد فترة**: النسخة المجانية بتنام بعد ربع ساعة بلا استخدام، وأول فتحة بتاخد حوالي 50 ثانية.
- **موديل كشف الوجه** (3.7MB) بينزل مرة وحدة من Google لسيرفرك وبيطلع للاعبين من نفس السيرفر.
- أحسن تجربة: موبايل قدّام الوجه بإضاءة منيحة، والوجه كله بالكادر.

## التشغيل محلياً

```bash
npm install
npm start
# افتح http://localhost:3000  أو  http://localhost:3000/?demo=1
```

| `public/index.html` | الشاشات والتصميم (نيو-بروتاليزم هادي · استعارة العدسة) |
| `public/app.js` | منطق القعدة: اللوبي، العجلة، الجولات، النقاط، الفرق، الرهان، الكشف |
| `public/games.js` | الكاميرا والألعاب العشرة |
| `public/story.js` | رسم صورة الستوري والألبوم |
| `render.yaml` | إعدادات النشر على Render |
